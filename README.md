# Trail Manager System

A Java-based trail management application that uses custom data structures to organize landmark, trail, and route data.

This project demonstrates object-oriented programming, custom data structure implementation, file-based data processing, black-box testing, and unit-tested Java development.

## Overview

Trail Manager System is designed to manage park and trail-related data, including landmarks, trails, and route information. The system loads structured input data, stores records using custom data structures, and supports organized lookup and reporting functionality.

The goal of this project was to practice building a data-focused Java application without relying heavily on built-in collection libraries. Instead, the project emphasizes custom data structures, clean class design, file processing, and testable program logic.

## Features

- Java application for managing trail and landmark records
- Custom data structures for storing and retrieving information
- File-based input processing
- Organized output generation
- Search and lookup functionality
- Manager classes for separating data logic from reporting logic
- JUnit tests for validating internal behavior
- Black-box test plan for validating expected program behavior
- Modular object-oriented design

## Tech Stack

- Java
- Custom Data Structures
- Linked Lists
- Binary Search Trees
- JUnit
- File I/O
- Black-Box Testing
- Object-Oriented Programming
